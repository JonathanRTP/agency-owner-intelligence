# 2-minute demo script

**0:00–0:20 — Problem**
“Owner Intelligence is built around one principle: unreliable data should not become confident decisions. I start by applying the challenge's conversation rule before showing business metrics.”

**0:20–0:45 — Trust layer**
“Carrier answered is not treated as a conversation. I also separate the documented non-person PBG Billing account and keep callbacks out of appointment counts.”

**0:45–1:15 — Owner view**
“Here the owner can see reported sales, applications, confirmed interactions, appointments and spend. The agent table is designed to answer where attention is needed rather than just display activity.”

**1:15–1:35 — Data quality**
“I found records where speaker activity conflicts with the source disposition. I don't silently rewrite them; I surface them as data-quality signals for investigation.”

**1:35–1:50 — AI**
“The optional AI layer sits after the deterministic metric engine. The model receives validated metrics and explains them; it does not calculate or invent the underlying numbers.”

**1:50–2:00 — Close**
“The MVP prioritizes reliable business reasoning, clean engineering and a practical path toward an AI-enabled product.”
